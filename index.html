ferry

Copy a Claude Code chat as a .jsonl file from one computer to another. Git still moves the source code. Ferry packs and unpacks the conversation file.

Install (Mac, Homebrew)

brew tap lindsay-cheng/ferry https://github.com/lindsay-cheng/ferry
brew install ferry

Homebrew needs a public GitHub repo and a git tag. Until then, use curl or pipx below.

Install (curl)

curl -fsSL https://raw.githubusercontent.com/lindsay-cheng/ferry/main/install.sh | bash

Checks only (no install): curl -fsSL https://raw.githubusercontent.com/lindsay-cheng/ferry/main/install.sh | bash -s -- --check

If the GitHub repo is private and curl returns 404, clone the repo and run ./install.sh, or pipx install git+https://github.com/lindsay-cheng/ferry.git.

Move a chat with a file

On computer A, export the chat:

ferry export auth-refactor

Send the auth-refactor.jsonl file (Slack, AirDrop, email, USB). Ferry does not upload it.

On computer B, import and open in Claude:

ferry import -o

The jsonl is the raw chat, including secrets pasted into Claude. Do not commit the export.
