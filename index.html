weave

Share Claude Code sessions between machines. Mac/Linux, Python 3.11+.

Weave moves the conversation, not git.

Install

Private repo — use GitHub auth (gh logged in, or git credentials):

gh api -H "Accept: application/vnd.github.raw" \
  repos/lindsay-cheng/weave/contents/install.sh | bash

Checks only (no install): pipe to bash -s -- --check instead of bash.

Once this page is on a public host: curl -fsSL https://YOUR_HOST/install.sh | bash
