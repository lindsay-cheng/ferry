ferry

Share Claude Code sessions between machines. Mac/Linux, Python 3.11+.

Ferry moves the conversation, not git.

Install

curl -fsSL https://raw.githubusercontent.com/lindsay-cheng/ferry/main/install.sh | bash

Checks only (no install): curl -fsSL https://raw.githubusercontent.com/lindsay-cheng/ferry/main/install.sh | bash -s -- --check

If the GitHub repo is private and curl 404s, clone the repo and run ./install.sh, or pipx install git+https://github.com/lindsay-cheng/ferry.git.
